# История проекта

## Предисловие

Проект вырос из практической задачи: настольная диктовка на русском, которая работает **без интернета** и не требует ни аккаунта, ни лицензионного ключа. Ниже — как он собирался, шаг за шагом: какие решения принимались и почему.

## 1.0.1 — диагностика вставки

Появилось после реального случая: у пользователя текст доезжал до буфера обмена, но не попадал ни в одно окно — и программа молчала, потому что результат `SendInput` не проверялся.

- **Вставка больше не врёт.** Считаем, сколько событий приняла система. Если `Ctrl+V` заблокирован — автоматически пробуем напечатать текст посимвольно; если и это не проходит, текст остаётся в буфере, а пользователь видит объяснение причины.
- **Настройки → «Проверить вставку».** Обратный отсчёт 3 секунды, затем тестовая строка уходит в активное окно. В ответе — число принятых событий: `4` значит система ввод приняла, `0` — блокирует (обычно «защита ввода» антивируса или права администратора).
- **Исправлен редкий случай**, когда окно программы ошибочно считалось активным из-за совпадения PID: теперь дополнительно проверяется, что процесс окна жив.

## 1.0.0 — первый рабочий релиз

**Движок.** Выбор сразу пал на GigaAM v3 от GigaChat Team: для русского языка она точнее универсальных моделей и при этом компактна. Взяли конвертацию под `sherpa-onnx` в int8 — 221 МБ вместо 400+ и нормальная скорость на процессоре. Проверка: 15,5 с аудио распознаются за 0,56 с (RTF 0,04), пунктуация и числа на месте без дополнительной обработки.

**Горячая клавиша.** Первая версия на `RegisterHotKey` повела себя неожиданно: `Ctrl+Space` регистрировался успешно, но событие не приходило ни на физическое нажатие, ни на синтетическое. Причина — подсистема ввода перехватывает сочетания с `Space` раньше. Решение: низкоуровневый хук `WH_KEYBOARD_LL`, который видит и нажатие, и отпускание, и умеет «проглатывать» сочетание.

**Микрофон.** Оказалось, что первые ~0,24 с после открытия аудиопотока теряются — обрезался первый слог. Решение: поток остаётся «тёплым» 25 секунд после диктовки и прогревается при запуске. Параллельно пришлось перебирать частоты: WASAPI не всегда принимает 16 кГц.

**Вставка текста.** Реализована двумя способами: буфер обмена с восстановлением прежнего содержимого и симуляция клавиш через `SendInput` с Unicode. Проверялась на собственном окне Win32 с полем `EDIT` — сверка по `WM_GETTEXT`, чтобы убедиться, что доходит именно нужный текст, включая «ёжик», кавычки-ёлочки и длинное тире.

**Интерфейс.** Сознательно без фреймворков: HTML/CSS/JS, локальный HTTP-сервер на стандартной библиотеке Python. Окно — Chromium-браузер в режиме приложения. Тёмная и светлая темы, индикатор уровня, drag-and-drop файлов, история со статистикой.

**Плавающий индикатор записи.** Понадобился после первого теста: при диктовке в чужое окно не видно, идёт ли запись. Сделан нативным слоистым окном с отрисовкой через GDI+: per-pixel alpha, скруглённые углы, 30 кадров в секунду, прозрачность для мыши и без захвата фокуса.

**Трей и закрытие окна.** Крестик закрывает только окно; программа остаётся в трее и продолжает слушать клавишу. При закрытии показывается уведомление, что она работает в фоне, — иначе поведение выглядит как «программа выключилась».

**Починка вставки при закрытом окне.** Обнаружился дефект: признак «интерфейс в фокусе» приходил из браузера и залипал, если окно закрывали, — текст уходил только в буфер. Теперь активность определяется по реальному активному окну Windows.

**Упаковка.** PyInstaller (папка, не один файл — так быстрее старт), Inno Setup 6 для установщика: установка для текущего пользователя без UAC, ярлыки на рабочем столе и в «Автозагрузке», запись в «Установленных приложениях», корректное удаление с вопросом о сохранении истории.

**Что сознательно не вошло.** Голосовые команды через ИИ (нужен интернет), автозамена по таблице правил, «умная вставка по контексту» — всё это усложняет продукт и не относится к главной задаче: быстро и локально превратить голос в текст.

## Технические находки, которые стоит помнить

| Наблюдение | Вывод |
|---|---|
| `RegisterHotKey` молчит для сочетаний с `Space` | нужен `WH_KEYBOARD_LL` |
| Первые 0,24 с записи теряются | держать поток «тёплым» |
| WASAPI: `AUDCLNT_E_UNSUPPORTED_FORMAT` на 16 кГц | перебирать частоты и откатываться на системное устройство |
| Флаг фокуса из браузера залипает при закрытии окна | проверять реальное активное окно |
| ctypes без `argtypes`/`restype` обрезает 64-битные дескрипторы | объявлять прототипы WinAPI |
| `GdipCreateFont` ждёт объект семейства, а не строку | создавать `GdipCreateFontFamilyFromName` |
| `SendInput` в неактивное окно ничего не делает | вставлять после явной проверки фокуса |
