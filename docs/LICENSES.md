# Сторонние компоненты и лицензии

Стенограф — самостоятельная программа. Она не содержит проверок лицензии, активации, телеметрии, аналитики, рекламных идентификаторов и автообновления. Единственный сетевой запрос, который программа способна сделать, — загрузка модели по **явному** нажатию кнопки «Скачать модель» (адрес huggingface.co). В обычной работе программа работает только с локальным портом `127.0.0.1`.

## Что это значит на практике

Программа собрана только из свободных компонентов и **не требует GPL-кода**. `ffmpeg` в комплекте — **LGPL-сборка** (только декодирование, без GPL-кодеков вроде x264): этого достаточно для mp3, m4a, mp4 и остальных поддерживаемых форматов.

Единственный нюанс — **pystray** (LGPL-3.0): LGPL требует возможности заменить библиотеку. Исходный код программы открыт, поэтому её можно заменить, пересобрав проект; для строгого соответствия достаточно приложить папку `app/` к своему дистрибутиву.

Хотите другую сборку ffmpeg — замените `tools\ffmpeg.exe` на свою, программа подхватит её автоматически.

## Чего в программе нет

- Нет сетевой активации, пробных периодов, ключей и «звонков домой».
- Нет аналитики и счётчиков посещаемости.
- Нет автообновлений и фоновых загрузок.
- Нет скрытых служб, драйверов и автозапуска без вашего выбора (автозагрузка — только галочка в инсталляторе).
- Нет сбора содержимого диктовок: история хранится в `data\history.json` на этом компьютере и никуда не отправляется.
